## Current competitive operating model

1. **Against Scale AI:** Sell **Neutrality + Sovereign FDE**. Never let a prospect treat Scale as the only enterprise evaluation partner—highlight IP sovereignty, direct senior engineering access, and zero competing foundation-model ownership.
2. **Against Palantir:** Sell **FDE Velocity Without the Ransom**. Praise Palantir's FDE execution model, then show how Innodata delivers the same embedded engineering velocity in 2–4 weeks inside the customer's existing `GCP`, `AWS`, or `Azure` environment at a fraction of the TCO.
3. **Against Mercor / Turing / Surge / Invisible:** Sell **Managed Systems Over Headcount**. Expose the hidden tax of managing individual contractors and boutique shops; pitch Innodata as the single-MSA consolidation partner.
4. **Against Appen / TELUS / Sama / TaskUs / CloudFactory / iMerit:** Sell **Agentic & ARE Depth Over Crowd Volume**. Shift the evaluation criteria from cost-per-label to multi-step trajectory reliability, red teaming, and full-stack software delivery.
5. **Against Labelbox / Snorkel / SuperAnnotate / Kognic:** Sell **Outcomes Over Licenses**. Ask who on the customer's team has time to operate another SaaS tool when Innodata delivers the finished pipeline, SMEs, and deployed agent.
