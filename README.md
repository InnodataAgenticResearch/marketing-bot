## 1. Key Capabilities & Operating Invariants

1. **Upstream ArtBOT Public Contract Lock (`UPSTREAM_ARTBOT.json`):** Pins `InnodataAgenticResearch/artbot` at tag `v0.2.0-artbot` (`b3fbc3b87fd7b1e561f1d78f179ba31dcf64cb81`). `checks/api_contract.star` forbids importing private `artbot` submodules or underscore-prefixed symbols.
2. **Agility PR Dual-Transport Intelligence (`src/marketing_bot/agility_mcp.py`):**
   - Streamable HTTP JSON-RPC 2.0 MCP client (`POST https://apigateway.agilitypr.com/api/mcp` with `apiKey` header) supporting `initialize`, `tools/list`, and `ad_hoc_search` across both JSON and SSE (`data: {...}`) streams.
   - REST API client (`https://mediaintelligence.agilitypr.com/api/v1`) supporting `GET /topic` and `POST /topic/search` across all 17+ monitored brand and competitor topics.
3. **Innodata Enterprise AI Strategy Engine (`src/marketing_bot/strategy.py`):** Scores (`0.00–1.00`), deduplicates, and maps every media mention against Innodata's 6-pillar full-stack engineering taxonomy, 5 proprietary accelerators, GTM wedge, and 5 competitive cohorts.
4. **Mention-Only Microsoft Teams Discipline:** Only responds when `@marketing-bot` (or `@artbot`) is explicitly mentioned in unquoted text and replies strictly in-thread (`replyToId` + `messageId`).

## 2. Creating a Microsoft Teams Workflows Webhook (Launch Your Own Bot)

To connect **Marketing-Bot** to a Microsoft Teams channel without requiring Entra ID tenant-wide admin consent:

1. In Microsoft Teams, open the target channel, click **`...` (More options) -> Workflows**.
2. Select the **"Post to a channel when a webhook request is received"** template.
3. Name the workflow `Marketing-Bot Adaptive Card Bridge`, authenticate with your M365 account, and select the target Team and Channel.
4. Copy the generated Power Automate HTTP POST URL and store it in your runtime `.env` file (never committed to git) as:
   ```bash
   TEAMS_WEBHOOK_URL="https://<tenant>.<region>.environment.api.powerplatform.com:443/powerautomate/automations/direct/workflows/..."
   ```
5. Open the workflow in [make.powerautomate.com](https://make.powerautomate.com) and set **"Who can trigger the flow"** to **Anyone** so the bridge can post Adaptive Cards using the signed URL.

## 3. End-to-End Setup & Configuration

1. Enter the reproducible Nix development environment:
   ```bash
   nix develop
   ```
2. Configure runtime environment variables in `~/.hermes/profiles/marketingbot/.env`:
   ```bash
   AGILITYPR_API_KEY="<your-agilitypr-api-key>"
   TEAMS_WEBHOOK_URL="https://<tenant>.<region>.environment.api.powerplatform.com/..."
   ARTBOT_CARD_TITLE="Marketing-Bot (Innodata PR & Market Intelligence)"
   ```
3. Verify upstream ArtBOT pin and Innodata strategy configuration:
   ```bash
   PYTHONPATH=src:vendor python3 -m marketing_bot.cli upstream-status
   PYTHONPATH=src:vendor python3 -m marketing_bot.cli strategy-summary
   ```

## 4. Runtime Execution

- **Generate Daily Intelligence Roundup (Offline Seed or Live Agility PR):**
  ```bash
  # Deterministic seed / offline generation for a specific date:
  PYTHONPATH=src:vendor python3 -m marketing_bot.cli generate-daily --date 2026-11-06

  # Live harvest across Agility PR MCP + Saved Topics when AGILITYPR_API_KEY is set:
  PYTHONPATH=src:vendor python3 -m marketing_bot.cli generate-daily --date 2026-11-06 --live

  ```
